# Hydraulics

An online textbook for the undergraduate Hydraulics course in the Department of Civil Engineering, Jeonbuk National University, by [Daeha Kim](https://daehakim-waterlab.github.io/).

Figures and tables are generated by the Python code that accompanies them, which runs every time the book is built. Click "Show code cell source" below a figure to see its code.

The whole book is also available as a [PDF](https://daehakim-waterlab.github.io/hydraulics/hydraulics.pdf).
